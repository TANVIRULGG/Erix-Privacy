# Erix

Erix is a Discord moderation and community-management bot built with discord.js and MongoDB.

## Features
- AutoMod: invite-link filter, bad-word filter and excessive-caps filter, with configurable actions, log channel and whitelists
- Invite tracking, invite log and leaderboards
- Welcome messages
- Giveaways, timers, polls and moderation commands
